# Software

The robot's software is maintained by Lynn Ong at **[lynnlo/leaf-detector](https://github.com/lynnlo/leaf-detector)**.

To include it in this repository as a linked copy that stays up to date:

```bash
git submodule add https://github.com/lynnlo/leaf-detector.git software/leaf-detector
```

See the main [README](../README.md#software) for what each script does and how to run it.
